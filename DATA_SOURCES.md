# Источники данных v4.2.1

## 1. Международные результаты

Базовая история сборных с 2010 года формируется из открытого набора международных матчей. Она используется для Elo, формы, силы соперников, Dixon–Coles и основной ML-модели.

## 2. FIFA

Текущий и исторический рейтинг FIFA обновляется автоматически. Для исторического матча используется только рейтинг, опубликованный до его даты.

## 3. football-data.org

При наличии API-ключа используется для:

- календаря и статусов матчей;
- результатов;
- счёта первого тайма, когда доступен;
- стартовых составов;
- дополнительной матчевой статистики, когда провайдер её возвращает.

Покрытие зависит от соревнования и доступности конкретного ресурса.

## 4. StatsBomb Open Data

Автоматический сбор пытается получить открытые международные соревнования и извлечь:

- xG;
- удары и удары в створ;
- угловые;
- карточки;
- счёт первого тайма;
- события;
- составы и историю использования игроков.

Open Data покрывает только выбранные турниры. Пропуски не заменяются выдуманными значениями.

## 5. Составы и игроки

Составы проверяются при прогнозе и отдельным GitHub Action. Если обе стартовые одиннадцатки опубликованы, модель пересчитывает относительную силу состава и потери ключевых игроков. До публикации используется прогноз без поправки на состав.

## 6. Скрытая рыночная проверка

The Odds API подключается необязательно. Она используется только для внутренней проверки:

- что кандидат не относится к слишком короткой очевидной линии;
- что вероятность модели выше очищенной от маржи рыночной вероятности.

Коэффициенты не выводятся на сайт и не сохраняются в журнал.

Без ключа применяется математическое приближение: события с модельной вероятностью выше `1 / 1.40` исключаются из неочевидного выбора.

## 7. Активация специализированных моделей

Первый тайм, второй тайм, угловые и карточки включаются не только по количеству строк. Каждая модель:

1. сортирует матчи по времени;
2. обучается на прошлом;
3. проверяется на более новых матчах;
4. сравнивается с простым средним;
5. калибрует тоталы;
6. включается только при приемлемом качестве.

## 8. Защита от утечки будущего

Для обучения каждого исторического матча используются только признаки, известные до его начала. Тестирование, калибровка и селектор неочевидного исхода разделяются хронологически.
