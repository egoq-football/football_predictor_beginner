# Источники данных и ограничения

## Результаты сборных

Проект использует открытый CSV международных матчей:

`https://github.com/martj42/international_results`

Файл обновляется командой `python train.py --download`.

## Рейтинг FIFA

- исторические снимки: открытый CSV `Dato-Futbol/fifa-ranking`;
- текущий снимок: публичный FIFA ranking endpoint, если он доступен;
- при недоступности автоматического endpoint можно загрузить CSV вручную через сайт.

При обучении исторического матча используется последний рейтинг, опубликованный не позднее даты матча. Современный рейтинг не подставляется в старые матчи.

## Расширенная статистика

`data/enriched_match_stats.csv` — пользовательский объединяющий слой. Сюда можно добавлять данные из источника, лицензия которого разрешает такое использование.

Поддерживаются xG, удары, удары в створ, угловые, карточки, владение, PPDA и счёт первого тайма.

StatsBomb Open Data может использоваться для исследований и содержит JSON матчей, событий и составов для выбранных соревнований, но не покрывает всю историю всех сборных. При использовании необходимо соблюдать условия и указывать источник StatsBomb.

## Составы игроков

`data/player_pool.csv` не заполняется автоматически, потому что свободный полный и единообразный источник актуальных рейтингов, минут, травм и заявок всех 48 сборных не встроен в проект. Пользователь может заполнить файл вручную или подключить лицензированный API.

## Что программа не делает

- не выдумывает xG, угловые, карточки или составы;
- не гарантирует выигрыш;
- не использует будущие результаты при историческом тестировании;
- не заменяет профессиональный поставщик спортивных данных.
