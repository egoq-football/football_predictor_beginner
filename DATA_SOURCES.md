# Автоматические источники данных

## 1. Календарь, результаты, таблицы и стартовые составы

Основной машинно-читаемый источник — football-data.org. Бесплатный API-ключ хранится только в Streamlit Secrets и GitHub Actions Secrets.

Сайт автоматически использует:

- календарь ЧМ-2026;
- статусы и результаты матчей;
- таблицу группы, вычисленную по завершённым матчам перед выбранной встречей;
- стартовые составы, когда провайдер их публикует.

Если API временно недоступен, используется встроенный снимок официального календаря FIFA. Прогноз не падает, но текущая таблица и составы могут быть не самыми свежими.

## 2. Рейтинг FIFA

Текущий рейтинг запрашивается автоматически из публичного FIFA ranking endpoint. При ошибке остаётся последний успешно сохранённый снимок.

Исторические рейтинги используются на дату конкретного матча, чтобы не было утечки будущей информации.

## 3. Результаты сборных с 2010 года

Используется открытый набор международных матчей martj42/international_results.

## 4. Расширенная статистика и игроки

GitHub Actions запускает `update_open_sources.py`. Скрипт пытается получить доступные мужские чемпионаты мира из StatsBomb Open Data и автоматически рассчитывает:

- xG;
- удары и удары в створ;
- угловые;
- карточки;
- приближённое владение;
- счёт первого тайма;
- историю стартовых составов;
- прозрачный прокси-рейтинг игрока на основе частоты использования в сборной.

Open Data не покрывает все матчи и не заменяет коммерческий спортивный API. Поэтому модель использует показатель только там, где он реально доступен, и не заполняет пропуски выдуманными значениями.

## 5. Ограничения

- Полные продвинутые метрики всех 48 сборных бесплатно и единообразно не доступны.
- Стартовый состав обычно появляется примерно за час до игры, но точное время зависит от источника.
- Если состав или расширенная статистика отсутствуют, прогноз считается без соответствующей поправки.
