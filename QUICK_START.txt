WORLD CUP 2026 PREDICTOR v4.1

1. Upload all files from this folder to the root of your GitHub repository.
2. Wait for Streamlit to redeploy app.py.
3. Create a free football-data.org token.
4. In Streamlit Cloud -> Manage app -> Settings -> Secrets add:

[data_sources]
football_data_api_key = "YOUR_TOKEN"

5. In GitHub repository -> Settings -> Secrets and variables -> Actions add:
FOOTBALL_DATA_API_KEY = your token

HOW TO USE
- Select a real World Cup 2026 fixture.
- Click "Сделать прогноз".
- Do not enter date, round, points, goal difference or lineups manually.
- If lineups are not published yet, the prediction is calculated without them.
- Reopen the same match after lineups are published to get the lineup-adjusted prediction.
