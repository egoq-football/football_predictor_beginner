WORLD CUP 2026 PREDICTOR v4.3

1. Загрузите все файлы в корень GitHub-репозитория.
2. Убедитесь, что загрузились .github/workflows/retrain.yml и live_refresh.yml.
3. GitHub: Settings → Actions → General → Read and write permissions.
4. GitHub: Settings → Secrets and variables → Actions → FOOTBALL_DATA_API_KEY.
5. Actions → Update data and retrain model → Run workflow.
6. Дождитесь зелёной галочки.
7. Streamlit Cloud → Manage app → Reboot app.

Workflow сам удалит повреждённые строки расширенной статистики и заново рассчитает покрытие.
