# Настройка счётчика онлайна и истории посещений

Патч использует бесплатную базу Supabase. В GitHub никакие ключи загружать нельзя.

## 1. Создать проект Supabase

1. Откройте Supabase и создайте новый проект.
2. Дождитесь, пока база будет готова.
3. Откройте `SQL Editor`.
4. Нажмите `New query`.
5. Откройте файл `supabase_analytics.sql` из этого патча.
6. Скопируйте весь SQL в редактор и нажмите `Run`.

После успешного запуска появится таблица `site_sessions` и три защищённые функции.

## 2. Скопировать URL и ключи

В Supabase откройте:

`Project Settings -> API Keys`

Скопируйте:

- Project URL;
- Publishable key (`sb_publishable_...`), либо старый `anon` key;
- Secret key (`sb_secret_...`), либо старый `service_role` key.

Secret key предназначен только для серверной закрытой страницы статистики. Его нельзя публиковать в GitHub, сообщениях или документах.

## 3. Добавить Streamlit Secrets

Откройте приложение в Streamlit Community Cloud:

`Manage app -> Settings -> Secrets`

Добавьте к уже существующим секретам:

```toml
[site_analytics]
supabase_url = "https://ВАШ_PROJECT_REF.supabase.co"
publishable_key = "sb_publishable_..."
secret_key = "sb_secret_..."
admin_password = "ПРИДУМАЙТЕ_СЛОЖНЫЙ_ПАРОЛЬ"
timezone = "Europe/Berlin"
```

Не удаляйте существующие разделы `[data_sources]` и `[github_journal]`.

Сохраните Secrets и перезагрузите приложение.

## 4. Что появится

На главной странице:

- `Сейчас онлайн`;
- `Посещений сегодня`;
- `Всего посещений`.

Счётчик обновляется примерно каждые 30 секунд. Посетитель считается онлайн, если его браузер подавал сигнал в последние 2 минуты.

В боковом меню появится страница `Статистика посещений`. Она закрыта паролем из `admin_password` и показывает:

- онлайн сейчас;
- посещения сегодня;
- посещения за 7 дней;
- общее число посещений;
- график и таблицу по дням;
- последние сеансы и их длительность;
- выгрузку CSV.

## Ограничение подсчёта

Система не собирает IP-адреса, имена, email или другие персональные данные. Поэтому она считает активные браузерные сеансы, а не гарантированно уникальных людей. Новая вкладка, другой браузер или повторное подключение иногда считаются новым посещением.
