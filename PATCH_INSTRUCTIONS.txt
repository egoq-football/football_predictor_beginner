FOOTBALL PREDICTOR v4.6 — ТОЧНОСТЬ И КОМПАКТНЫЙ ОНЛАЙН-СЧЁТЧИК

1. Распакуйте архив.
2. Откройте внутреннюю папку football_predictor_v4_6_accuracy_patch.
3. В GitHub откройте Code → Add file → Upload files.
4. Загрузите ВСЁ содержимое внутренней папки с заменой существующих файлов.
5. Нажмите Commit changes.
6. Откройте Actions → Update data and retrain model → Run workflow.
7. После зелёной галочки: Streamlit → Manage app → Reboot app.

Папка data в патче отсутствует: ваши результаты, составы, журнал и статистика
посещений не удаляются.

Папка models включена, чтобы сайт сразу получил совместимую модель v4.6.
Она обучена на комплекте данных по 11.06.2026. После запуска Actions модель
пересчитается на самых свежих данных вашего репозитория.

Что изменено:
- хронологические out-of-fold прогнозы для метамодели;
- раздельная калибровка победы первой команды, ничьей и победы второй;
- удалено искусственное class_weight=balanced, которое могло завышать ничьи;
- матчи взвешиваются по свежести и турнирной важности;
- обучаемое смешивание метамодели с устойчивым консенсусом базовых моделей;
- контроль ECE и Brier отдельно по каждому исходу перед принятием модели;
- индикатор расхождения базовых моделей;
- большой блок счётчиков убран; маленький индикатор «N онлайн» находится справа внизу.
