# Football Predictor — первая версия для новичка

Это учебно-практическая программа для прогноза футбольных матчей сборных.
Она берет открытые данные международных матчей, считает признаки, обучает модель и выдает прогноз.

## Что умеет первая версия

- скачивает открытый CSV с результатами международных матчей;
- считает силу команд через собственный Elo-рейтинг;
- считает форму последних матчей;
- учитывает личные встречи;
- обучает модель машинного обучения;
- добавляет простой объясняемый нечеткий слой по принципу правил «если — то»;
- считает ожидаемые голы и вероятные счета;
- запускается через простой веб-интерфейс Streamlit.

## Установка на Windows

### 1. Установить Python

Скачай Python с официального сайта: https://www.python.org/downloads/

Во время установки обязательно поставь галочку:

```text
Add Python to PATH
```

### 2. Распаковать проект

Распакуй папку `football_predictor_beginner` в удобное место, например на Рабочий стол.

### 3. Открыть командную строку в папке проекта

В папке проекта нажми на адресную строку Проводника, напиши:

```text
cmd
```

и нажми Enter.

### 4. Создать виртуальное окружение

В открывшемся черном окне введи:

```bat
python -m venv .venv
```

### 5. Включить виртуальное окружение

```bat
.venv\Scripts\activate
```

Если слева в строке появилось `(.venv)`, всё нормально.

### 6. Установить библиотеки

```bat
pip install -r requirements.txt
```

### 7. Запустить приложение

```bat
streamlit run app.py
```

После этого откроется браузер с программой.

## Как пользоваться

1. В левой панели нажми **Скачать/обновить данные**.
2. Подожди, пока данные загрузятся.
3. Выбери две команды.
4. Укажи, нейтральное поле или нет.
5. Нажми **Сделать прогноз**.

## Быстрый пример без интерфейса

Можно запустить прогноз через консоль:

```bat
python predict_cli.py
```

## Важно

Это первая рабочая версия, а не букмекерская «машина денег».
Модель работает только с историческими результатами матчей сборных.
Она пока не учитывает реальные составы, травмы, новости, xG, PPDA и продвинутую статистику.
Это добавляется следующими этапами.
