# Football Predictor v4.4 patch

Небольшое обновление интерфейса и получения официальных стартовых составов.

## Исправления

- длинное техническое объяснение селектора исходов больше не отображается;
- составы сначала проверяются через football-data.org, затем через открытый ESPN endpoint;
- резервный источник определяется по дате и паре команд, поэтому идентификаторы матчей не зашиты вручную;
- используются только футболисты, явно помеченные как стартовые;
- фамилии игроков отображаются в двух колонках во вкладке «Составы и данные»;
- фоновое обновление составов работает и без ключа football-data.org через резервный источник;
- вероятности основной модели не изменены.

## Файлы патча

- `app.py`
- `football_predictor/world_cup_live.py`
- `football_predictor/market_selector.py`
- `live_refresh.py`
- `update_open_sources.py`
- `tests/test_lineup_sources.py`

## Установка

Загрузить содержимое папки в корень репозитория с заменой одноимённых файлов, затем перезапустить приложение Streamlit.
