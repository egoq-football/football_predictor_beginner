# World Cup 2026 Predictor v4

Программа предназначена специально для прогнозирования матчей чемпионата мира 2026. Она не использует вручную назначенные доли вроде «30% FIFA + 20% форма». Итоговые вероятности формирует обучаемая метамодель, которая сравнивает несколько независимых моделей и сама определяет их полезность на исторических данных.

## Что уже реализовано

- международные матчи начиная с 1 января 2010 года;
- исторический рейтинг FIFA на дату каждого матча;
- внутренний динамический рейтинг Elo;
- последние 3, 5 и 10 матчей;
- усиленная оценка последних пяти матчей с поправкой на силу соперников;
- Dixon–Coles для ожидаемых голов, точного счёта, тоталов и «обе забьют»;
- отдельная модель машинного обучения для исхода 1X2;
- обучаемая метамодель вместо ручных весов;
- температурная калибровка процентов;
- турнирная ситуация ЧМ-2026: тур группы, очки, разница мячей, необходимость победы, достаточность ничьей, отдых и ротация;
- отдельная логика группового этапа и плей-офф;
- вероятность дополнительного времени и итогового прохода в плей-офф;
- модуль оценки состава;
- отдельные модели первого тайма, второго тайма, угловых и карточек;
- сравнение с FIFA, Elo, Dixon–Coles, отдельной ML-моделью и простым базовым прогнозом;
- хронологический тест без подглядывания в будущее;
- отдельные проверки на ЧМ-2014, ЧМ-2018 и ЧМ-2022;
- журнал прогнозов с последующей записью фактических результатов;
- автоматический кандидат на переобучение: новая модель принимается только при улучшении Log Loss;
- ежедневный GitHub Actions workflow для обновления данных, обучения и заполнения результатов журнала.

## Важное ограничение

Полная история xG, ударов, угловых, карточек и составов всех сборных не существует в одном бесплатном открытом источнике. Поэтому программа не выдумывает недостающие показатели.

В архиве есть готовая архитектура и шаблоны CSV. Модели таймов, угловых и карточек автоматически включатся после появления достаточного количества заполненных строк:

- первый и второй тайм: не менее 250 матчей;
- угловые: не менее 350 матчей;
- карточки: не менее 350 матчей.

До этого сайт честно показывает, что соответствующая модель недоступна.

# Как обновить существующий сайт

## 1. Сделай резервную копию

Скачай текущий репозиторий GitHub через **Code → Download ZIP**. Это позволит вернуться к старой версии.

## 2. Загрузи новую версию

1. Распакуй архив `football_predictor_v4.zip`.
2. Открой папку `football_predictor_v4`.
3. Открой свой репозиторий:
   `https://github.com/egoq-football/football_predictor_beginner`
4. Нажми **Add file → Upload files**.
5. Перетащи всё содержимое папки `football_predictor_v4`.
6. Папку `.venv` загружать не надо — её в архиве нет.
7. Нажми **Commit changes**.
8. Streamlit автоматически пересоберёт сайт. Обычно это занимает несколько минут.

Главный файл приложения по-прежнему:

```text
app.py
```

## 3. После обновления

1. Открой сайт.
2. Нажми слева **Обновить рейтинг FIFA**.
3. Проверь дату последнего рейтинга в боковой панели.
4. Сделай первый прогноз.

Если сайт показывает старую версию, открой **Manage app → Reboot app**.

# Как пользоваться прогнозом

## Групповой этап

1. Выбери группу.
2. Выбери две команды.
3. Укажи тур группы: 1, 2 или 3.
4. Введи очки обеих команд перед матчем.
5. Введи текущую разницу мячей.
6. Укажи количество дней отдыха.
7. Укажи риск ротации.
8. Отметь, если победа обязательна или ничьей достаточно.
9. Нажми **Сделать прогноз**.

На третьем туре программа также делает осторожные автоматические выводы: команда с 0–1 очком рассматривается как нуждающаяся в победе, а команду с 4 и более очками может устраивать ничья. Ручные отметки имеют приоритет.

## Плей-офф

1. Выбери **Плей-офф**.
2. Выбери две команды.
3. Укажи отдых, ротацию и составы.
4. Сделай прогноз.

Сайт отдельно покажет:

- исход после 90 минут;
- вероятность дополнительного времени;
- вероятность итогового прохода каждой команды.

## Составы

Пока файл `data/player_pool.csv` пуст, используй ползунок «Сила состава, % от оптимального».

Пример:

- основной состав без потерь: 100%;
- отсутствует один важный игрок: примерно 94–98%;
- несколько ключевых потерь: примерно 85–94%;
- сильно ослабленный состав: ниже 85%.

После заполнения базы игроков сайт позволит выбирать реальный стартовый состав.

# Что означают вкладки

## Обоснование

Показывает рейтинг FIFA, форму с поправкой на силу последних соперников, турнирную мотивацию и влияние составов.

## Наиболее вероятные исходы

Показывает самый вероятный вариант в каждой категории: 1X2, двойной шанс, тотал, обе забьют, точный счёт, а при наличии данных — таймы, угловые и карточки.

Вероятности разных категорий связаны между собой. Они не являются гарантией результата.

## Голы и точный счёт

Строится по матрице счетов Dixon–Coles. Она учитывает атакующую и оборонительную силу команд и отдельно корректирует низкие счета 0:0, 1:0, 0:1 и 1:1.

## Таймы, угловые, карточки

Каждая категория использует отдельную модель. Она активируется только при достаточном количестве исторических строк.

## Составы и данные

Показывает силу выбранного состава и реальное покрытие расширенной статистики.

## Модели

Показывает прогнозы отдельных слоёв:

- машинное обучение;
- Dixon–Coles;
- Elo;
- FIFA;
- последние матчи с учётом силы соперников;
- итог после метамодели и калибровки.

## Тестирование

Показывает Accuracy, Log Loss и Brier Score. Для вероятностного прогноза важнее прежде всего Log Loss и Brier Score, а не только количество угаданных победителей.

## Журнал

Сохраняет прогноз до начала матча. После завершения можно записать фактический результат и увидеть накопленную точность.

# Как работает обучение

Программа делит матчи только по времени:

1. ранняя часть — обучение базовых моделей;
2. следующая часть — обучение метамодели;
3. следующая часть — калибровка процентов;
4. последняя часть — честный итоговый тест.

Будущие матчи не используются для обучения прошлых прогнозов.

При переобучении создаётся кандидат. Он сравнивается с текущей моделью по Log Loss. Кандидат заменяет действующую модель только при достаточном улучшении. Поэтому модель может обучаться автоматически, но не должна бесконтрольно принимать любую новую версию.

## Ручной запуск обучения на Windows

Открой командную строку в папке проекта и выполни:

```bat
.venv\Scripts\activate
python train.py --download
```

Проверка на прошлых чемпионатах мира:

```bat
python backtest_world_cups.py
```

# Автоматическое переобучение

Файл `.github/workflows/retrain.yml` запускается ежедневно и также может запускаться вручную.

После загрузки проекта:

1. Открой GitHub.
2. Перейди во вкладку **Actions**.
3. Выбери **Update data and retrain model**.
4. Нажми **Run workflow** для первой проверки.

Если workflow не может отправить изменения:

1. Открой **Settings → Actions → General**.
2. Найди **Workflow permissions**.
3. Разреши **Read and write permissions**.
4. Сохрани настройки.

Автоматический процесс:

1. обновляет архив результатов;
2. пытается обновить рейтинг FIFA;
3. обучает кандидата;
4. сравнивает его с текущей моделью;
5. обновляет фактические результаты в журнале;
6. запускает тесты на прошлых чемпионатах мира;
7. сохраняет изменения в GitHub.

# Постоянный журнал на Streamlit Cloud

Локальный файл на Streamlit Cloud может исчезать после перезапуска контейнера. Для постоянного журнала используется GitHub Contents API.

## 1. Создай ограниченный токен GitHub

Создай fine-grained personal access token только для репозитория `football_predictor_beginner` с правом:

```text
Contents: Read and write
```

## 2. Добавь секреты в Streamlit

1. Открой приложение в Streamlit Cloud.
2. Нажми **Manage app → Settings → Secrets**.
3. Вставь:

```toml
[github_journal]
token = "ТВОЙ_GITHUB_TOKEN"
repo = "egoq-football/football_predictor_beginner"
path = "data/prediction_log.csv"
branch = "main"
```

4. Сохрани и перезапусти приложение.

Никогда не добавляй настоящий токен в файл GitHub. Файл `.streamlit/secrets.toml.example` — только пример.

# Как добавить расширенную статистику

Заполняй `data/enriched_match_stats.csv`.

Обязательные идентификаторы матча:

```text
date, home_team, away_team
```

Доступные показатели:

```text
home_xg, away_xg
home_shots, away_shots
home_shots_on_target, away_shots_on_target
home_corners, away_corners
home_yellow_cards, away_yellow_cards
home_red_cards, away_red_cards
home_possession, away_possession
home_ppda, away_ppda
home_ht_score, away_ht_score
```

После добавления строк:

1. замени CSV в GitHub;
2. запусти **Обновить матчи и обучить кандидата** на сайте или GitHub Action;
3. проверь вкладку «Составы и данные»;
4. после достаточного покрытия соответствующие модели включатся автоматически.

Не смешивай статистику разных матчей и не заполняй отсутствующие значения выдуманными числами.

---

# Как добавить игроков

Заполняй `data/player_pool.csv`:

```text
team,player,position,rating,club_minutes_90d,national_caps,available
```

Где:

- `rating` — единая числовая оценка игрока в одной шкале для всех команд;
- `club_minutes_90d` — минуты за клуб за последние 90 дней;
- `national_caps` — матчи за сборную;
- `available` — `TRUE` или `FALSE`.

Для корректного сравнения нельзя использовать разные шкалы рейтинга для разных команд.

## Принцип честности

Программа повышает качество оценки вероятностей, но не может гарантировать исход футбольного матча. Журнал, хронологический тест и сравнение с базовыми моделями нужны именно для того, чтобы видеть реальную, а не заявленную точность.
