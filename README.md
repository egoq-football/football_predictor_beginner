# Football Predictor — версия 3.1

Программа прогнозирует матчи национальных сборных на основе открытой истории матчей, рейтинга FIFA и нескольких математических моделей.

## Изменения версии 3.1

- используются все завершённые матчи начиная с 1 января 2010 года;
- исторические несуществующие сборные исключены из списка выбора;
- последние пять матчей и рейтинг FIFA вместе дают ровно 50% итогового прогноза;
- математические модели также дают ровно 50%:
  - машинное обучение — 25%;
  - модель Пуассона — 20%;
  - нечёткие правила — 5%;
- внутри машинного обучения более свежие матчи имеют больший вес, но старые матчи с 2010 года не удаляются;
- если рейтинг FIFA для команды недоступен, его доля временно переносится на последние пять матчей, при этом баланс 50/50 сохраняется;
- во вкладке «Техника модели» показаны как два основных блока, так и детальные веса.

## Итоговые веса при доступном рейтинге FIFA

| Компонент | Вес |
|---|---:|
| Последние 5 матчей | 30% |
| Рейтинг FIFA | 20% |
| Машинное обучение | 25% |
| Модель Пуассона | 20% |
| Нечёткие правила | 5% |

## Запуск локально

```bat
.venv\Scripts\activate
streamlit run app.py
```

## Обновление Streamlit Cloud

1. Распакуй архив.
2. Загрузи содержимое папки в корень GitHub-репозитория.
3. Нажми `Commit changes`.
4. Streamlit Cloud автоматически перезапустит приложение.
5. После обновления старый файл модели будет признан несовместимым и модель переобучится при первом прогнозе.

Главный файл приложения: `app.py`.
