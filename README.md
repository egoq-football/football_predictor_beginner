# Football Predictor — версия 3.2

Программа прогнозирует матчи мужских национальных сборных по открытым данным, начиная с 2010 года.

## Изменения версии 3.2

- удалены полосы вероятностей под итоговым прогнозом;
- разница рейтинга FIFA теперь объясняется как небольшая, заметная, значительная или очень большая;
- последние 5 матчей оцениваются с учётом силы соперников;
- в машинное обучение добавлены средний Elo последних соперников, результат относительно ожидания Elo и форма с поправкой на силу календаря;
- «Вероятности по слоям модели» вынесены в отдельную вкладку;
- удалены лишние поясняющие надписи и таблица ключевых числовых признаков;
- добавлено понятное объяснение внутреннего рейтинга Elo;
- наиболее вероятные счета рассчитываются по средним забитым и пропущенным голам обеих команд, с весом 75% для последних 5 матчей и 25% для последних 10;
- сохранён баланс прогноза: последние 5 матчей и FIFA — 50%, математические модели — 50%.

## Как обновить сайт

1. Распакуй архив.
2. Открой репозиторий `football_predictor_beginner` на GitHub.
3. Нажми `Add file` → `Upload files`.
4. Перетащи содержимое папки проекта, а не саму внешнюю папку.
5. Нажми `Commit changes`.
6. Подожди автоматического перезапуска Streamlit Cloud.

После обновления первый прогноз будет дольше обычного, потому что модель автоматически переобучится с новыми признаками.

## Локальный запуск

```bat
.venv\Scripts\activate
streamlit run app.py
```
