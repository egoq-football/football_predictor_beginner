# World Cup 2026 Predictor v4.3

Версия 4.3 исправляет ошибки качества данных и состава, обнаруженные после первого автоматического обновления.

## Что исправлено

- корректно читаются `home_team_name` и `away_team_name` из StatsBomb;
- повреждённые строки без команд и ложные нулевые строки удаляются;
- повторы матчей больше не ломают объединение данных;
- покрытие xG, таймов, угловых и карточек считается только по валидным матчам, сопоставленным с основной базой;
- прогноз до публикации составов остаётся нейтральным и не использует предполагаемый состав как официальный;
- после появления обеих стартовых одиннадцаток прогноз пересчитывается;
- показатель игроков переименован по смыслу: это индекс использования в сборной, а не коммерческий рейтинг;
- фиктивные `900` клубных минут больше не создаются;
- лучший неочевидный исход проходит фильтры вероятности, согласия моделей, качества данных и скрытую рыночную проверку при наличии API;
- очевидная победа сильного фаворита исключается из неочевидных рекомендаций;
- GitHub Actions обновлены до Node 24-совместимых `actions/checkout@v6` и `actions/setup-python@v6`;
- перед обучением запускаются очистка данных и автоматические тесты;
- добавлена защита от одновременной записи двух workflow.

## Установка обновления

Загрузите содержимое этой папки в корень GitHub-репозитория с заменой существующих файлов. Папки `.github` и `.streamlit` должны быть видимы в Проводнике Windows: **Вид → Показать → Скрытые элементы**.

После загрузки:

1. Откройте **Actions → Update data and retrain model**.
2. Нажмите **Run workflow**.
3. Workflow очистит старые повреждённые строки, заново соберёт доступные данные, запустит тесты и переобучит модели.
4. После зелёной галочки откройте Streamlit Cloud и выполните **Manage app → Reboot app**.

## Секреты

В Streamlit Cloud:

```toml
[data_sources]
football_data_api_key = "ВАШ_КЛЮЧ"
odds_api_key = "НЕОБЯЗАТЕЛЬНЫЙ_КЛЮЧ"
```

В GitHub Actions создайте секрет `FOOTBALL_DATA_API_KEY`.

`odds_api_key` используется только для скрытой проверки рынка. Коэффициенты на сайте не отображаются.

## Проверка локально

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python validate_data.py --fix
streamlit run app.py
```

## Ограничения

Открытые источники не гарантируют полное покрытие xG, угловых, карточек и составов всех сборных. Модель соответствующего рынка активируется только после достаточного количества валидных матчей и успешной хронологической проверки. Недостающие значения не выдумываются.
