# World Cup 2026 Predictor v4.1 — автоматические данные

Эта версия убирает ручной ввод турнирной информации. Пользователь выбирает реальный матч чемпионата мира 2026, а программа сама определяет календарь, положение в группе, дни отдыха, мотивацию, доступность составов и актуальный рейтинг FIFA.

## Что изменилось

- Нет ручных полей для даты, номера тура, очков и разницы мячей.
- Матч выбирается из календаря ЧМ-2026.
- Очки и разница мячей вычисляются по завершённым матчам группы до выбранной встречи.
- Дни отдыха, необходимость победы, достаточность ничьей и риск ротации рассчитываются автоматически.
- Стартовые составы загружаются автоматически, когда источник их публикует.
- Если составов ещё нет, прогноз выполняется без поправки на игроков.
- После публикации составов достаточно повторно открыть матч и снова нажать «Сделать прогноз».
- Рейтинг FIFA обновляется автоматически; ручная кнопка и загрузка CSV удалены.
- Расширенная статистика и история игроков пополняются из StatsBomb Open Data, когда соответствующие матчи доступны в открытом наборе.
- Обоснование теперь показывает отдельную таблицу факторов, а не длинный набор общих фраз.

## Как обновить сайт

1. Распакуй архив.
2. Открой папку проекта.
3. В GitHub открой репозиторий `egoq-football/football_predictor_beginner`.
4. Нажми `Add file -> Upload files`.
5. Загрузи всё содержимое папки, включая скрытые папки `.github` и `.streamlit`.
6. Нажми `Commit changes`.
7. Подожди автоматического обновления Streamlit.

Главный файл приложения остаётся `app.py`.

## Однократная настройка текущих данных

Для автоматического получения результатов, таблиц и стартовых составов нужен бесплатный API token football-data.org.

### Streamlit Cloud

Открой:

`Manage app -> Settings -> Secrets`

Добавь:

```toml
[data_sources]
football_data_api_key = "ТВОЙ_TOKEN"
```

Сохрани настройки и перезапусти приложение.

### GitHub Actions

Открой:

`Repository -> Settings -> Secrets and variables -> Actions -> New repository secret`

Название:

`FOOTBALL_DATA_API_KEY`

Значение — тот же token football-data.org.

Без token сайт продолжит работать по встроенному календарю FIFA, однако текущие результаты, таблицы и составы могут обновляться с задержкой.

## Как пользоваться

1. Открой сайт.
2. Выбери матч в поле «Матч ЧМ-2026».
3. Нажми «Сделать прогноз».
4. Открой вкладки результата:
   - «Обоснование» — основные факторы и их направление;
   - «Наиболее вероятные исходы» — лучший вариант по каждой категории;
   - «Голы и точный счёт» — Dixon–Coles, тоталы и обе забьют;
   - «Таймы, угловые, карточки» — отдельные модели при достаточном покрытии данных;
   - «Составы и данные» — статус составов и покрытие открытых данных;
   - «Модели» — прогнозы отдельных слоёв и итог метамодели;
   - «Тестирование» — Accuracy, Log Loss, Brier Score и прошлые чемпионаты мира;
   - «Журнал» — сохранённые прогнозы и фактическая точность.

## Как работают составы

Примерно за час до матча источник обычно публикует стартовые составы. Программа проверяет их автоматически при нажатии «Сделать прогноз».

- Составы не опубликованы: модель не делает выдуманную поправку.
- Составы опубликованы, но мало истории игроков: используется нейтральная поправка и фиксируется факт известного состава.
- Есть история составов или открытые данные игроков: оцениваются потери наиболее часто использовавшихся футболистов и относительная сила стартовых 11.

## Автоматическое обновление

Файл `.github/workflows/retrain.yml` ежедневно:

1. обновляет результаты международных матчей;
2. обновляет рейтинг FIFA;
3. обновляет календарь и текущие результаты ЧМ-2026;
4. сохраняет доступные стартовые составы;
5. добавляет доступные открытые данные StatsBomb;
6. обучает модель-кандидата;
7. сравнивает её с действующей моделью;
8. принимает новую модель только при улучшении контрольного Log Loss;
9. обновляет журнал и отчёты тестирования.

## Источники и ограничения

Подробности приведены в `DATA_SOURCES.md`.

Программа использует только реально полученные показатели. Если открытый источник не предоставляет xG, угловые, карточки или состав, соответствующая модель не подставляет выдуманные значения.
