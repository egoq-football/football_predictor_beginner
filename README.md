# World Cup 2026 Predictor v4.2.1

Версия v4.2.1 автоматизирует сбор доступных данных, обучает отдельные модели для разных типов прогнозов и добавляет исторически обученный выбор **лучшего неочевидного исхода**. Коэффициенты на сайте не отображаются.

## Что реализовано

### Основной прогноз

- матчи сборных с 2010 года;
- исторические рейтинги FIFA на дату матча;
- внутренний Elo;
- последние матчи с поправкой на силу соперников;
- Dixon–Coles для счёта, тоталов и «обе забьют»;
- отдельная ML-модель 1X2;
- метамодель без вручную назначенных долей;
- калибровка итоговых процентов;
- турнирный контекст ЧМ-2026;
- автоматические таблицы групп, очки и разница голов;
- автоматические стартовые составы, когда они опубликованы;
- журнал прогнозов и хронологическое тестирование.

### Специализированные модели

Отдельно обучаются:

- первый тайм;
- второй тайм;
- угловые;
- жёлтые карточки.

Они включаются только после двух условий:

1. автоматический сбор получил достаточный объём пригодных матчей;
2. модель прошла хронологическую проверку не хуже простого среднего.

Поэтому сайт больше не показывает бессмысленные вероятности при пустой базе. Во вкладке отображается статус, период данных, алгоритм и качество проверки.

### Лучший неочевидный исход

Система рассматривает:

- 1X2;
- тоталы матча;
- индивидуальные тоталы;
- обе забьют;
- таймы;
- угловые и карточки, когда их модели активны.

Очевидные варианты исключаются. Максимально безопасные события с модельной вероятностью выше приблизительного эквивалента линии 1,40 не выбираются.

Встроенный селектор:

- обучается на исторических вневыборочных прогнозах;
- отдельно калибруется;
- учитывает вероятность, согласие моделей, качество данных, разницу FIFA/Elo и тип рынка;
- не использует вручную назначенные веса для итогового ранжирования;
- не предлагает вариант, когда подходящего кандидата нет.

При подключённом `odds_api_key` реальные линии используются только внутри программы, чтобы проверить минимальную линию и преимущество модели. Коэффициенты на сайте не выводятся. Без этого ключа применяется математический приближённый фильтр.

## Установка обновления

1. Распакуй архив.
2. Открой папку проекта.
3. В GitHub открой репозиторий `egoq-football/football_predictor_beginner`.
4. Нажми `Add file -> Upload files`.
5. Загрузи всё содержимое папки, включая скрытые `.github` и `.streamlit`.
6. Нажми `Commit changes`.
7. В Streamlit открой `Manage app -> Reboot app`.

Главный файл: `app.py`.

## Обязательная настройка данных

### 1. football-data.org

Нужен для текущего календаря, результатов и стартовых составов, когда они доступны.

В Streamlit Cloud:

`Manage app -> Settings -> Secrets`

```toml
[data_sources]
football_data_api_key = "ТВОЙ_TOKEN"
```

В GitHub:

`Settings -> Secrets and variables -> Actions -> New repository secret`

```text
Name: FOOTBALL_DATA_API_KEY
Value: тот же token
```

### 2. Необязательная скрытая проверка рынка

Для точной внутренней проверки условия примерно от 1,40 можно добавить ключ The Odds API:

```toml
[data_sources]
odds_api_key = "ТВОЙ_ODDS_API_KEY"
```

Ключ нужен только Streamlit-приложению. Коэффициенты не отображаются и не записываются в журнал.

### 3. Постоянный журнал

Чтобы прогнозы сохранялись прямо в GitHub, добавь:

```toml
[github_journal]
token = "github_pat_..."
repo = "egoq-football/football_predictor_beginner"
path = "data/prediction_log.csv"
branch = "main"
```

Без этого журнал работает локально внутри экземпляра Streamlit и может быть потерян после перезапуска.

## Первый запуск после обновления

1. Открой GitHub -> `Actions`.
2. Запусти вручную `Update data and retrain model`.
3. Дождись зелёной отметки.
4. При необходимости запусти `Refresh World Cup lineups and live context`.
5. Открой сайт и сделай прогноз.

В `Settings -> Actions -> General -> Workflow permissions` должны быть включены `Read and write permissions`.

## Как заполняются таймы, угловые и карточки

Пользователь ничего не вводит вручную.

`update_open_sources.py` автоматически пытается получить:

- счёт первого тайма;
- итоговый счёт, из которого считается второй тайм;
- угловые;
- карточки;
- xG;
- удары;
- составы;
- историю использования игроков.

Источники объединяются без замены реальных значений пустыми полями. Если источник не отдаёт показатель, он остаётся пропуском. После следующего ежедневного переобучения специализированная модель сама включится, если данные и проверка качества достаточны.

## Как пользоваться сайтом

1. Выбери реальный матч ЧМ-2026.
2. Нажми `Сделать прогноз`.
3. Смотри вкладки:
   - `Обоснование` — рейтинги, форма, сила соперников, ожидаемые голы, контекст и составы;
   - `Наиболее вероятные исходы` — лучший неочевидный вариант, альтернативы и лучшие исходы по категориям;
   - `Голы и точный счёт` — Dixon–Coles;
   - `Таймы, угловые, карточки` — активные специализированные модели и их проверка;
   - `Составы и данные` — статус составов и фактическое покрытие источников;
   - `Модели` — отдельные слои;
   - `Тестирование` — Log Loss, Brier, Accuracy и качество обученного селектора;
   - `Журнал` — сохранение прогноза до матча и последующая оценка.

Когда официальные составы появятся, повторно открой матч и нажми `Сделать прогноз`. Программа пересчитает результат с поправкой на доступных игроков.

## Автоматические процессы

### Каждые 30 минут во время турнира

`.github/workflows/live_refresh.yml` обновляет календарь, статусы и составы.

### Один раз в сутки

`.github/workflows/retrain.yml`:

1. обновляет открытые источники;
2. добавляет доступную расширенную статистику;
3. обучает модель-кандидата;
4. сравнивает её с действующей по Log Loss;
5. принимает новую версию только при улучшении;
6. обновляет журнал и бэктесты.

## Важные ограничения

- Бесплатные открытые источники не гарантируют полное единообразное покрытие всех международных матчей.
- Модели угловых и карточек не активируются, пока нет реальной истории и приемлемой хронологической проверки.
- Стартовый состав учитывается только после публикации источником.
- Без `odds_api_key` условие линии 1,40 оценивается приближённо по математической вероятности, а не по реальному рынку.
- Даже откалиброванный прогноз не гарантирует исход матча.
