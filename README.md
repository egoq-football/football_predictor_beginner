# Football Predictor — версия 2.1

Это программа для прогноза футбольных матчей сборных на открытых данных.

## Что добавлено/исправлено в версии 2.1

- больше статистики команд: Elo, форма, голы за 5 и 10 матчей, атака, оборона;
- последние матчи каждой команды;
- очные встречи;
- ожидаемые голы;
- вероятные счета;
- тоталы больше/меньше 1.5, 2.5, 3.5;
- вероятность «обе забьют»;
- вероятность сухого матча;
- сравнение трех слоев прогноза: машинное обучение, нечеткие правила, Пуассон;
- ускоренная усиленная модель: Logistic Regression + Random Forest + HistGradientBoosting;
- кэширование данных и модели, чтобы сайт не пересчитывал всё при каждом клике;
- первый экран открывается быстрее, модель готовится только при нажатии «Сделать прогноз»;
- автоматическая проверка совместимости старого файла модели.

## Как запустить локально

```bat
.venv\Scripts\activate
streamlit run app.py
```

## Как обновить сайт Streamlit Cloud

1. Скачай архив версии 2.
2. Распакуй его.
3. На GitHub открой репозиторий `football_predictor_beginner`.
4. Нажми `Add file` → `Upload files`.
5. Перетащи все файлы и папки из распакованной версии 2.
6. Нажми `Commit changes`.
7. Streamlit Cloud сам перезапустит сайт.
8. На сайте один раз поставь галочку `Переобучить модель` и нажми кнопку прогноза. После успешного прогноза галочку выключи.

Главный файл приложения: `app.py`.
